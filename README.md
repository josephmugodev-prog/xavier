# St. Xavier's High School — Website ZIP

Responsive static website for St. Xavier's High School, Afraha, Nakuru.

## Features
- Desktop navigation in a horizontal header; header hides on scroll down and reappears on scroll up.
- Mobile navigation in an accessible slide-out sidebar; closes after a link is selected, on backdrop click or Escape.
- About, academics/pathways, admission enquiry, fee structure, donations, virtual tour, uniform requirements and contact sections.
- Admission form opens WhatsApp to 0116450944 with the form details pre-filled. The parent/guardian must press Send.
- Supplied KCB, Paybill, M-Pesa, uniform and school contact details.
- Google Maps location, responsive layout, hover effects and subtle animations.

## Preview / upload
Open index.html in a browser. Upload index.html and the complete assets folder to your web root (usually public_html). Internet access is required for Bootstrap Icons and Google Fonts.

- Confirm postal code, current admissions dates and current fee schedule.
- Confirm exact Paybill account reference format. The supplied wording refers to 20495K plus student name and admission number without spaces; this site deliberately flags the format for confirmation.
- Confirm whether two trousers are correct under girls' uniform.
- Confirm current subject combination availability.
- Supply official donation channels/projects and virtual tour video/360 URL.
- Confirm official current uniform list and bank instructions.
