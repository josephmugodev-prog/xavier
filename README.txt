# St. Xavier's High School Website — Flat Project Structure

All project files are in ONE folder. There are no subfolders.

## Files
- `index.html` — website page
- `style.css` — all website styling
- `main.js` — navigation, slideshow and admission form behavior
- `image1.jpg` — first landing-page slideshow image
- `image2.jpg` — second landing-page slideshow image
- `image3.jpg` — third landing-page slideshow image
- `image4.jpg` — admission form background image

## Add images
Copy your four approved school photographs into this same folder as `index.html`, `style.css` and `main.js`. Name them exactly as listed above. Use `.jpg` filenames, or update the image references if you use another extension.

## Upload
Upload all files together into the website root (for example `public_html`). Do not create or upload an `assets` folder.

The site is static. The admission form opens WhatsApp to 0116450944 with the details prefilled; the parent/guardian must press Send. No database or payment processing is included.
